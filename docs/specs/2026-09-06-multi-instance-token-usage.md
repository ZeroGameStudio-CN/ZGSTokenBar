## 口径

基线 CodexTokenUsageReader 仅扫描一个 CODEX_HOME 的 sessions/archived_sessions。实例登记源为 Cockpit 的 codex_instances.json；已有配额导入将实例按账号去重，不可直接用于会话总量。

本机汇总范围为有效 CODEX_HOME（未设置时为默认 .codex）加全部登记的 Cockpit 实例目录。无论运行状态、账号是否绑定或是否重复，均按目录发现。沿用登记目录的托管根目录和非重解析点校验，不扫描用户主目录、未登记目录、NAS 或其他机器。

先合并所有候选文件，再统一计算 fork 基线与会话增量。同名 rollout 沿用已有文件键与最长副本选择，只计一次；跨实例父子会话可解析继承基线。原有持久索引继续合并保留，未重新发现的旧会话不删除。今日、缓存比例、消费历史使用同一覆盖范围。配额导入和账号活动判断行为不变。

用户后续选择独立账本口径：复用 codex-token-usage-index.json 的每会话累计、末次计数和完整行扫描位置，不另建数据库。累计展示只来自该账本，不再用过期官方账号快照作为累计下限；官方配额仍使用原接口。追加时复用已有顺序扫描器，跨计数器重置累加各段新增值，不只比较首尾两个计数；较短的旧副本不能覆盖已入账记录。删除或移动源文件后保留账本历史。重复副本沿用原文件身份，不重复计算。
