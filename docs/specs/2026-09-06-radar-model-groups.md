## 行为与边界

现有 RadarService 会合并上游摘要、完整测量与推荐数据；RadarPresentation 已按模型与推理档位排序。保留这条数据路径，不写固定模型白名单、不制造模型数据。

Codex 与 DeepSeek 雷达均按实际模型 ID（忽略大小写）生成标题行，点击标题折叠或展开其全部档位。新模型默认展开；Terra、Luna 默认折叠以满足最初的精简诉求，但不隐藏模型标题。标题使用方向箭头、模型名称，提供中英文操作提示。组内只显示档位，无档位时回退到原行标签。按用户验收反馈，GPT-6 Astra 组置顶，组内档位与其他组相对顺序保持不变。折叠不改变测量、推荐或排名。

按用户新增要求，折叠状态持久保存于现有 settings.json 的 radarModelGroups 字典（模型 ID 到折叠布尔值，忽略大小写），刷新、重启、关闭重开和费用历史返回均保留。仅记录用户操作；显式展开覆盖 Terra/Luna 默认折叠，新模型仍默认展开。旧配置没有字段时沿用默认，无破坏性迁移。设置窗口复制和保存必须保留最新选择，保存失败提示并恢复先前状态。点击分组沿用现有临时固定机制；外部点击和 Escape 行为不变。测试仅在临时目录读写合成配置。

表格具有受当前屏幕工作区约束的视口，内容超高时显示滚动条，支持滚轮、轨道点击与拖动。标题、列头、错误与底部信息不参与滚动。折叠或刷新后限制滚动偏移，所有折叠时仍显示组标题，不显示空数据提示。

## 范围和验证

影响 Core 雷达分组状态和布局、AppSettings、设置窗口复制、应用设置保存、App 浮窗及绘制、BarForm 临时固定事件、NativeText 提示、可执行回归测试和必要的源代码契约。保留 Token-only、费用历史、数据拉取和其他 Provider 行为。配置只由正常用户操作经应用保存，验收不修改生产配置；本机运行实例替换沿用用户授权，不涉及基础设施。

1. 合成 Astra 与未知未来模型的测量经过解析、合并后自动生成组；所有档位保留，无固定白名单。
2. Terra/Luna 初始折叠，可展开再折叠；刷新、模型大小写变化、暂时缺失不丢失用户选择；其他组不受影响。
3. 折叠只影响布局，不改变输入行、IQ leader 或推荐。全折叠仍能逐组展开。
4. 在 96/144/192 DPI、有限高度与大量合成模型下，无列头、页脚重叠；滚动到底可访问最后一组，偏移受限；鼠标命中与绘制使用同一几何。
5. 使用生产绘制器生成并检查中文和英文折叠/展开/滚动截图。运行 `npm run verify`，全部通过，并检查完整 diff；不要求用户操作 GUI 作为验收。
6. Astra 全部档位置于其他组之前，其他组相对顺序不变；真实临时配置保存、重新加载、重建状态后，显式折叠与展开均保留。设置窗口复制不丢失状态，不共享可变字典；无新字段的旧配置兼容。
